# huimoney 個人財務資產管理（測試版）

純前端網頁，主要功能：

- 📋 財務總覽、📈 股票管理（持股、買進、賣出、借券、股利、定期定額）、🛡️ 保險總覽、📊 全部資產一覽
- 📒 **記帳**：支出／收入、統計、圖表、搜尋、隨手記、付款方式、Excel 匯出入
- 🏦 **共同基金**：兩人共用基金的匯入、支出、結算與欠款
- 🎯 退休試算
- 📥 對帳單匯入（銀行、證券、信用卡、退撫儲金）、手機版畫面

程式以 All-MoneyBook 為底（2026-10-16 版），拿掉密碼鎖定和個人專用的分頁，加上退休試算、記帳與共同基金。

## 資料存在哪裡
- **先存在你自己的瀏覽器**（localStorage）。
- **登入雲端後會同步到雲端**（Firebase 專案 `huy-money`）：標題列「🔑 登入雲端同步」輸入 Email 和密碼；找不到帳號時，會先問你要不要建立新帳號。會同步的有：財務總覽、股票管理、保險總覽、全部資產一覽的每月紀錄、記帳（含共同基金）。
- **退休試算的設定目前只存在這個瀏覽器**，不會上雲端。
- 沒登入時，清除瀏覽器資料或換電腦，資料就不見了。
- **備份提醒：** 設定裡的「匯出備份（JSON）」和「匯出全部資料（Excel）」目前只包含財務總覽、股票、保險。**記帳、共同基金、退休試算還沒有包含進去**；記帳請到「📒 記帳 → ⚙️ 設定 → 備份」另外匯出。
- 標題列「☁️ 已同步」目前只代表財務總覽同步成功；記帳有自己的同步，失敗時只會跳出一次提示。

## 記帳與共同基金
- 記帳資料放在雲端 `ledger` 這一份文件裡（共同基金也在裡面）。
- 分類「共同基金」的支出，視為老婆匯進基金；有標記由基金付的支出，不算個人月支出。
- 「卡費」分類不計入月支出（避免信用卡消費和繳卡費重複算）。
- 銀行對帳單比對時，股票交割款會記成分類「股票交割」的支出或收入（目前**會**算進月支出／月收入，尚未排除）；現金股息、借券費會記成收入「股利」、「借券收入」。

## 退休試算
- 股票現值、每月定期定額可自動從「股票管理」帶入，也可手動輸入。
- 現金殖利率可選「過去一年實際領到」、「年度預估股利」或手動調整。
- 年齡、報酬率、退休專戶（可自行新增）都能自己改；一開始顯示的是範例數字。
- ⚠️ 這只是依你填的假設做簡單複利的概略推算，沒有考慮通膨、稅負、手續費，**不是投資建議**。

## 對帳單匯入
- 標題列「📥 匯入對帳單」：選 PDF 對帳單，在自己的裝置上讀取（PDF 不會上傳），確認後寫進股票買進／賣出／借券收入、財務總覽的銀行餘額、記帳（銀行明細與信用卡消費）、退休試算專戶（退撫儲金）。
- 目前認得：國泰證券、富邦證券、永豐金證券、台北富邦銀行、國泰世華銀行、第一銀行、永豐銀行、台新銀行、將來銀行、華南銀行、中國信託、台灣銀行、高雄銀行、玉山銀行、台北富邦信用卡、國泰世華信用卡、公教退撫儲金、私校退撫儲金。其他家的對帳單會顯示「認不出」。
- **對帳單解析檔不在這個 repo**：網頁直接載入 All-MoneyBook 網站上的 `scripts/stmt-parsers.js`。所以 All-MoneyBook 那邊改了解析檔，這裡會跟著變；那個網站連不上時，匯入對帳單會失敗。
- 圖片型 PDF（掃描檔）會自動用 OCR 讀，第一次使用會多載入一段文字辨識程式，比較慢。
- 讀 PDF 的程式（PDF.js）第一次使用時從網路載入。

## 部署（GitHub Pages）
Settings → Pages → Source 選 `main` 分支、根目錄 `/`，儲存後即可用網址開啟。

## 本機測試
在資料夾內執行 `python3 -m http.server 8000`，開 http://localhost:8000。
（圖表與 Excel 功能需要連網載入 Chart.js、ExcelJS。）

## 自動更新股價與匯率
- `.github/workflows/prices.yml` 會在台灣時間週一到週五 16:10 自動執行（`.github/scripts/fetch_prices.py`），抓台股（上市當天收盤、上櫃）、美股收盤價（Yahoo 優先、Stooq 備用）、美元兌台幣匯率，存成 `data/prices.json`；另外存每月月底收盤價到 `data/month-end/`（這個資料夾要等 Actions 第一次成功執行後才會出現），給「全部資產一覽」算比上個月增減。
- 任何一個來源抓不到，就沿用上一次的數字；證交所抓失敗時整個不更新。
- 也可以到 GitHub 的 Actions 頁面手動按「Run workflow」立刻跑一次。
- 網頁「股票管理」的「💹 更新股價與匯率」按鈕會讀這個檔，用**股票代號**對照更新現價和美元匯率；找不到代號的不會動。
- 開網頁時如果有「新的一天」的匯率會自動套用；同一天只套用一次，所以自己在標題列改的匯率會用到下次有新匯率為止。
- 美股要追蹤哪些代號，請編輯 `data/us-symbols.txt`。
- 首次使用請到 Settings → Actions → General，把 Workflow permissions 設為「Read and write permissions」。
