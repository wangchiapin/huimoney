# huimoney 個人財務資產管理（測試版）

純前端網頁：財務總覽、股票管理（持股、買進、賣出、借券、股利、定期定額）、保險總覽、全部資產一覽、退休試算，另有手機版畫面與對帳單匯入。

程式以 All-MoneyBook 為底（2026-10-16 版），拿掉密碼鎖定和個人專用的分頁，加上退休試算；雲端同步的程式保留但目前不接上（按登入只會跳提示）。

## 資料存在哪裡
所有資料只存在**你自己的瀏覽器**（localStorage）。雲端同步目前還沒開放。
清除瀏覽器資料或換電腦，資料就不見了——請定期用「匯出」功能下載 JSON／Excel 備份，換裝置時再「匯入」。

## 退休試算
- 股票現值、每月定期定額可自動從「股票管理」帶入，也可手動輸入。
- 現金殖利率可選「過去一年實際領到」、「年度預估股利」或手動調整。
- 年齡、報酬率、退休專戶（可自行新增）都能自己改；一開始顯示的是範例數字。
- ⚠️ 這只是依你填的假設做簡單複利的概略推算，沒有考慮通膨、稅負、手續費，**不是投資建議**。

## 對帳單匯入
- 標題列「📥 匯入對帳單」：選 PDF 對帳單，在自己的裝置上讀取（不會上傳），確認後寫進股票買進／賣出／借券收入。
- 目前認得：國泰證券、富邦證券、台北富邦銀行、國泰世華銀行。其他家的對帳單會顯示「認不出」。
- 讀 PDF 的程式（PDF.js）第一次使用時從網路載入。

## 部署（GitHub Pages）
Settings → Pages → Source 選 `main` 分支、根目錄 `/`，儲存後即可用網址開啟。

## 本機測試
在資料夾內執行 `python3 -m http.server 8000`，開 http://localhost:8000。
（圖表與 Excel 功能需要連網載入 Chart.js、ExcelJS。）

## 自動更新股價與匯率
- `.github/workflows/prices.yml` 會在台灣時間週一到週五 16:10 自動執行（`.github/scripts/fetch_prices.py`），抓台股（上市當天收盤、上櫃）、美股收盤價（Yahoo 優先、Stooq 備用）、美元兌台幣匯率，存成 `data/prices.json`；另外存每月月底收盤價到 `data/month-end/`，給「全部資產一覽」算比上個月增減。
- 任何一個來源抓不到，就沿用上一次的數字；證交所抓失敗時整個不更新。
- 也可以到 GitHub 的 Actions 頁面手動按「Run workflow」立刻跑一次。
- 網頁「股票管理」的「💹 更新股價與匯率」按鈕會讀這個檔，用**股票代號**對照更新現價和美元匯率；找不到代號的不會動。
- 開網頁時如果有「新的一天」的匯率會自動套用；同一天只套用一次，所以自己在標題列改的匯率會用到下次有新匯率為止。
- 美股要追蹤哪些代號，請編輯 `data/us-symbols.txt`。
- 首次使用請到 Settings → Actions → General，把 Workflow permissions 設為「Read and write permissions」。
